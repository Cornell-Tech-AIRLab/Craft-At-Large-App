Craft@Large Robot Studio

A Reachy Mini app for crafting circles. Each group writes how its robot should act, picks a voice and movements, saves versions, and tries them on the robot.

The groups

Using it on a robot

  1. Sign the robot in to Hugging Face with an account that can see this Space.
  2. Install Craft@Large Robot Studio from the robot's app list, then start it.
  3. On a laptop on the same Wi-Fi, open http://ROBOT-IP:7860/workshop and pick a group.

This page only describes the app. The app itself runs on the robot, and saved work stays on the robot.
